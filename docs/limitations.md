# Limitations

S.A.R.A.H. was developed as an assistive technology research prototype rather than a production safety system.

## Hardware Availability

The original implementation was tested using a borrowed ZED2 camera. That hardware is no longer available, so the reconstructed repository cannot currently reproduce the complete original hardware environment.

## Reconstructed Source

The original source repository was not preserved. The implementation in this repository is being reconstructed from archived project materials and recovered code.

As a result, it may not exactly match the final version used during the original demonstration.

## Model Reliability

Multimodal AI models can misidentify, omit, or hallucinate objects. S.A.R.A.H. should therefore not be treated as a replacement for established mobility aids or safety-critical navigation systems.

## Latency

Cloud inference introduces network and model latency, which can limit suitability for rapidly changing environments.

## Future Evaluation

A more complete evaluation would measure:

- hazard detection accuracy
- false-positive rate
- false-negative rate
- inference latency
- spatial localization accuracy
- interruption behavior
- user comprehension of spoken alerts
